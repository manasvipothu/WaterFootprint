A sleek, interactive web app that calculates the water footprint of everyday items — from food to clothing — and helps users make sustainable choices. Built with modern glassmorphism UI and interactive effects.

🚀 Features

🌊 Real-time Water Calculation – Input items & quantities, get instant results.

✨ Glassmorphism UI – Modern, clean, and futuristic design.

📱 Fully Responsive – Works beautifully on desktop, tablet & mobile.

💡 Educational Insights – Understand water usage and environmental impact.

🎨 Interactive Hero Effects – Optional water ripple and wave animations.

🔗 Easy Integration – Can be embedded in sustainability dashboards.

🛠️ Built With

HTML | CSS | JavaScript – Core frontend technologies

Boxicons – Sleek icons for UI

Glassmorphism – Modern design aesthetic
